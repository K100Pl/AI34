I.6.i - Topologies Rigides pour QCar2

Objectif: Definir deux topologies rigides pour un systeme multi-agents
compose de 1 leader et 2 followers (3 vehicules QCar2).


RAPPEL THEORIQUE

Condition de rigidite en 2D:
- Nombre minimum d'edges pour rigidite: 2N - 3
- Pour N = 3 vehicules: 2 x 3 - 3 = 3 edges minimum
- Une topologie avec 3 edges pour 3 robots est minimalement rigide


TOPOLOGIE 1 : TRIANGLE

Formation geometrique:
- Les 3 vehicules forment un triangle equilateral
- Le leader est a l'avant, les 2 followers sont derriere

Schema:
```
           Leader (1)
            /    \
           /      \
          /        \
      F1 (2) ---- F2 (3)
```

Edges: (1,2), (1,3), (2,3) = 3 edges

Matrice Laplacienne L1:
```
     [ 2  -1  -1 ]
L1 = [-1   2  -1 ]
     [-1  -1   2 ]
```

Offsets (formation triangle):
- Leader (1): (0, 0)
- F1 (2):     (-0.3, -0.4)
- F2 (3):     (0.3, -0.4)

Proprietes:
- Topologie symetrique
- Tous les agents sont connectes entre eux
- Tres stable car chaque agent a 2 voisins
- Adaptee pour navigation en espace ouvert


TOPOLOGIE 2 : PLATOON (Ligne)

Formation geometrique:
- Les 3 vehicules forment une ligne (file indienne)
- Le leader est a l'avant, F1 au milieu, F2 a l'arriere

Schema:
```
      Leader (1)
          |
          |
       F1 (2)
          |
          |
       F2 (3)
```

Edges: (1,2), (2,3), (1,3) = 3 edges

Note: Pour garantir la rigidite, on garde l'edge (1,3) meme
si F2 est "loin" du leader. Sans cet edge, la formation
ne serait pas rigide (seulement 2 edges = chaine flexible).

Matrice Laplacienne L2:
```
     [ 2  -1  -1 ]
L2 = [-1   2  -1 ]
     [-1  -1   2 ]
```

Offsets (formation platoon):
- Leader (1): (0, 0)
- F1 (2):     (0, -0.4)
- F2 (3):     (0, -0.8)

Proprietes:
- Formation compacte en largeur
- Adaptee pour passages etroits
- Necessite edge (1,3) pour rigidite


COMPARAISON DES DEUX TOPOLOGIES

                    TRIANGLE        PLATOON
Forme               Triangulaire    Ligne
Largeur             Large           Etroite
Edges               3               3
Matrice L           Identique       Identique
Rigide              Oui             Oui
Usage               Espace ouvert   Passage etroit


REMARQUE IMPORTANTE

Les deux topologies ont la MEME matrice Laplacienne car elles ont
les memes connexions (tous les agents connectes entre eux).

La DIFFERENCE est dans les OFFSETS qui definissent la forme
geometrique desiree:
- Triangle: offsets en triangle
- Platoon: offsets en ligne

La topologie (matrice L) garantit la RIGIDITE.
Les offsets definissent la FORME.


APPLICATION AUX QCar2

Pour les QCar2, les memes principes s'appliquent:
- Modele cinematique: voiture (Ackermann) au lieu d'unicycle
- Contraintes: rayon de braquage minimum
- Les offsets doivent etre adaptes a la taille des QCar2

Adaptation recommandee:
- Distances inter-vehicules plus grandes (~1m au lieu de 0.4m)
- Prendre en compte l'encombrement des vehicules
